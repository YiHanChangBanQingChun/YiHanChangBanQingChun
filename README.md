## 🧭 About me

I'm a **master's student in Surveying and Mapping Engineering at South China Normal University (SCNU)**. My undergraduate studies in **GIS at Guangzhou University (GZHU)** shaped my interest in spatial analysis, remote sensing, and web mapping.

I enjoy working through the full process: collecting and checking data, exploring spatial patterns, and building interactive tools to share the results.

- 🌍 **Research interests:** eldercare facility accessibility, urban services, and geospatial data analysis.
- 🛠️ **Building:** Python data pipelines and Vue-based WebGIS applications.
- 🛰️ **Learning:** remote sensing image processing, machine learning, and scientific computing with Python & MATLAB.
- 🏃 **Beyond the screen:** distance running—and turning my own training data into maps and visualizations.

本科就读于广州大学 GIS 专业，目前为华南师范大学测绘工程硕士研究生。用代码整理数据，用地图理解空间，也用跑步认识城市。
